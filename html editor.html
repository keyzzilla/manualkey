CHAPTER 1

The Architecture of a Webpage

Before writing code, you must understand the DOM (Document Object Model). HTML is essentially a tree of branches.

1. The Root (!DOCTYPE)

Every file starts with <!DOCTYPE html>. This isn't a tag; it's a message to the browser saying: "Prepare for modern HTML5 rules".

2. The Brain (Head)

The <head> contains metadata. This is where you tell the browser things like the title of the tab or what language the site is in. You also put your <style> here.

3. The Body

This is where the user spends their time. Everything visible—text, images, videos—must be inside the <body> tags.

CHAPTER 2

Step-by-Step Mastery

Follow this exact process to build a new component:

Step 1: Content First

Write your raw text using <p> for paragraphs or <h1> for big titles.

Step 2: Grouping

Wrap your related content in a <div>. Think of a <div> as an invisible box that holds items together.

Step 3: Styling (CSS)

Use the style section. For example, to center everything in your box, you would use: text-align: center;. To add space inside the box, use padding.

.my-box { background-color: #141414; border: 1px solid #ff4d00; padding: 20px; border-radius: 8px; }
